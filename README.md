# Filter Adults

Фильтрация массива пользователей по возрасту через цикл и условие.

## Задача
Написать функцию `filterAdults(users)`, которая принимает массив объектов вида `{ name: 'Иван', age: 17 }` и возвращает **новый массив** только с пользователями, чей возраст больше или равен 18.

## Что реализовано
- Функция `filterAdults(users)` с одним параметром — массивом пользователей.
- Классический цикл `for` для перебора массива по индексу.
- Проверка условия `users[i].age >= 18` внутри цикла.
- Накопление подходящих пользователей в новый массив `adultUsers` через `push`.
- Возврат нового массива через `return` — исходный `users` не мутируется.
- Вывод результата в консоль через отдельный цикл `for`.

## Технологии
- JavaScript
- Без фреймворков и библиотек.

## Как запустить
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.
3. Открыть DevTools → Console — там будет результат.

## Структура проекта
```
├── index.html   — пустая разметка для подключения скрипта
└── app.js       — массив users, функция filterAdults, вывод результата
```
